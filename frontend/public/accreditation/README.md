# Accreditation / membership logos

Drop the official logo files here (SVG preferred, PNG with transparent background is fine).
The footer (`CustomerFooter.tsx`) references these exact filenames:

- `trade-license.svg`
- `ecab.svg`
- `basis.svg`

Recommended: ~40px tall render, so export at 2x (≈80px tall) for crispness.
Until a file is added, its `<img>` slot shows the name as alt text.
